Turkey Run — The Great Thanksgiving Escape: a turkey flees the farmer across the farmyard, the pumpkin garden and the kitchen yard to the woods, 1500 m to freedom. Jump, flap and slide past hay bales, fences, puddles, clotheslines, rolling pumpkins, ovens and the swinging carving knife; eat corn, grab golden feathers for a shield, and don't let the farmer catch up — every stumble brings him closer. A complete, original, dependency-free HTML5 canvas game with a title screen, a HUD (score, distance, stage, lives, corn and feathers), caught and escaped end screens, synthesized WebAudio music and sound, and keyboard, mouse and touch controls.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
